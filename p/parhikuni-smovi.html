S.M.O.V.I.

Es la implementación de un simulador de manejo para la capacitación de los conductores de Parhíkuni con el software American Truck Simulator, donde se añadieron modificaciones para tener los autobuses con el diseño que se pintan las unidades de ruta, el uso de centrales de abastos, la subida de pasajeros y la realización de los viajes en mapas de México.

Este simulador incluye una modificación al programa "ETS2/ATS Telemetry Web Server + Mobile Dashboard” creado por Funbit para añadir la función de una botonera física manejada por arduino y que se conecta por conexión serial al mismo, añadiendo las funciones de: encendido conllave, direccionales, limpia-parabrisas, freno de estacionamiento, faros, control crucero y ajustar laaltura de la suspensión

Este programa también nos permite guardar los datos de telemetría que nos genera ATS para en un futuro hacer una evaluación de la manera en que maneja cada conductor.

Los componentes utilizados para este proyecto son:

  • American Truck Simulator
  • Mapas de México, Map mods for truck sims por Team Reforma
  • Mapas dlc de ATS necesarios para que funcione el mod de Team reforma.
  • Mod centrales por digitalmgs
  • Mod de pasajeros por digitalmgs
  • Mod de autobus MarcoPolo Paradiso g8 y wheels pack por cd3dshop
  • Mod Mexican traffic pack por Jazzycat
  • Skin para el autobús
  • Arduino Uno
  • Versión modificada de ets2-telemetry-server (original por Funbit)
  • Botones con serigrafía personalizada
  • Switch de luces de Chevy C2
  • Switch para llave de autobus
  • Switch para intermitentes de VolksWagen
  • Palanca genérica de 4 posiciones
  • Volante, pedales y palanca de velocidades Logitech
  • 3 monitores
  • Asiento vanling
