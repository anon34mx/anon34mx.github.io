Parhíkuni.com

Esta es la web principal ante el público de Destinos Parhíkuni SA de CV, aquí se promociona la venta en línea y se publicitan los distintos servicios que ofrece la empresa: viajes de ruta, paquetería y alquiler de autobuses.
Este sitio web cuenta con una interface moderna, adaptativa y responsiva para brindar la mejor experiencia al cliente desde cualquier resolución de pantalla, fácil legibilidad del texto, el texto es completamente responsivo, y visualmente atractiva.
Este sistema fue creado con PHP, utilizando el framework Laravel, bootstrap y para la base dedatos MySql.

En la sección de Destinos encontramos los lugares a dónde podemos viajar y los medios de contacto para cada oficina; en Factura, una breve guía de cómo tramitar la factura de su compra; el Blog, es la nueva sección donde publicamos noticias y momentos importantes para la empresa, este cuenta con su propio editor de texto (privado) hecho a medida; la sección de ayuda es donde se recopilan las preguntas frecuentes sobre el servicio y en la sección de nosotros se habla sobre la historia de la empresa.

Un complemento a este sitio es el cambio visual que se hizo en https://ventas.parhikuni.com.mx, donde cambiamos los estilos CSS.

Blog

Añadí un editor de texto privado para el blog, este editor es muy sencillo y sólo permite texto plano, pero es suficiente para las necesidades de la empresa. Funciona con algunos atributos html y css pero para minimizar el uso de estos lenguajes se manejan los elementos multimedia con la misma sintaxis de los objetos Json.

{ "tipo":"image", "id":1, "titulo":"imagen a la derecha, en línea con el texto", "alinear":"derecha" }

Después se procesa el texto con funciones bien perronas, de PHP para renderizar el texto en html.
Primero se encuentra el patró de texto { "" : "" } con la función preg_replace_callback, se le envía como argumentos la clase y la función que procesará el texto y el texto a procesar.

$reemp=preg_replace_callback( '/{.*?}/', [$this,'procesarJson'], $this->descripcion );

Dependiendo del tipo de contenido se puede recuperar imagenes, videos, audios, previamente subidos, se les da un tamaño, alineación, texto descriptivo o si es código de ejemplo se escapa el texto.
