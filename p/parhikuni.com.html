Parhíkuni.com

Esta es la web principal ante el público de Destinos Parhíkuni SA de CV, aquí se promociona la venta en línea y se publicitan los distintos servicios que ofrece la empresa: viajes de ruta, paquetería y alquiler de autobuses.

Este sitio web cuenta con una interface moderna, adaptativa y responsiva para brindar la mejor experiencia al cliente desde cualquier resolución de pantalla, fácil legibilidad del texto, el texto es completamente responsivo, y visualmente atractiva. Este sistema fue creado con PHP, utilizando el framework Laravel, bootstrap y para la base dedatos MySql.

En la sección de Destinos encontramos los lugares a dónde podemos viajar y los medios de contacto para cada oficina; en Factura, una breve guía de cómo tramitar la factura de su compra; el Blog, es la nueva sección donde publicamos noticias y momentos importantes para la empresa, este cuenta con su propio editor de texto (privado) hecho a medida; la sección de ayuda es donde se recopilan las preguntas frecuentes sobre el servicio y en la sección de nosotros se habla sobre la historia de la empresa.

Un complemento a este sitio es el cambio visual que se hizo en https://ventas.parhikuni.com.mx, donde cambiamos los estilos CSS.
