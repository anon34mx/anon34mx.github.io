Hostess

Este sistema se creó para el momento de abordar a un autobús.
El pasajero llega con su boleto físico o digital, la Hostess escanea el boleto, el sistema hace una serie de validaciones para saber si los datos del boleto son correctos, después se procede a pesar el equipaje del pasajero, con una bascula conectada por medio de un puerto serial al navegador, si excede del límite permitido de 25KG se genera un costo de $15 pesos por cada 5KG, después se procede con el pago y se manda a imprimir en papel térmico un comprobante con el que el pasajero pueda recuperar su equipaje al llegar a su destino y una etiqueta foliada por el sistema para cada pieza, sea maleta, mochila, bolsa, etc.

Cuando el autobús sale también se imprime la relación de pasajeros con los equipajes por si se requiere identificar al dueño en alguna caseta por órdenes de la autoridad o para aclaraciones, así mismo al terminar el turno se genera el corte deventa. Este sistema corre una aplicación hecha con Node para poder enviar a la impresora los PDF resultantes de los procesos, así como antes se usaba para gestionar la conexión serial con la bascula y enviar la información a la web.
