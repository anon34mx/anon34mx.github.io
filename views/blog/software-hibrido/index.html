Software híbrido

Por muchos años el software se ha dividido en dos: software de escritorio o software web. El software de escritorio se ejecuta desde el mismo equipo del usuario, mientras que el software web cumple el protocolo cliente-servidor, se usa atravéz de un equipo que envía la información a un servidor que la procesa y genera un resultado. Ambos esquemas tienen sus ventajas y desventajas; web es más fácil de desarrollar pero no podemos utilizar los recursos del equipo, el software de escritorio sí pero ---.
Esta era mi propuesta para el Sistema Integral
Ventajas:

  • Impresiones
    • Mandar a imprimir desde web, sin recuadro de confirmación
    • Configurar varias impresoras a la vez
  • Utilizar periféricos USB/COM
    • Escáneres
    • Lectores biométricos
    • Monederos/billeteras/terminales de pago/etc.
  • Seguridad
    • Validación de hardware
    • Validacipon al enviar formularios
    • Evitar que el usuario abra la consola de desarrollador (con contraseña)
  • Productividad
    • Evitar que el usuario acceda a otros sitios web
